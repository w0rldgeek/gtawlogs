# Абоненты — приложение для актуализации номеров

Настольное приложение в **отдельном окне** со **своей собственной базой
данных** — отдельным текстовым файлом (не Excel). Ни сервера, ни
хостинга, ни облака.

## Поля

- **Адрес**
- **Логин**
- **Дата**
- **Номер телефона**

Записи раскладываются по месяцам. Быстрый ввод, поиск/фильтр, удаление.

## Своя база данных = текстовый файл

База хранится в простом **`.txt` файле**, который удобно открыть и
читать в «Блокноте» — записи сгруппированы по месяцам:

```
АБОНЕНТЫ — база данных
Обновлено: 12.06.2026 16:10
Записей: 3
Формат строки:  ДД.ММ.ГГГГ | Адрес | Логин | Номер

================  Июнь 2026  ================
12.06.2026 | Vinewood Blvd, 12 | john | 5551234
03.06.2026 | Grove St, 1 | cj | 5550001

================  Май 2026  ================
20.05.2026 | Mirror Park, 7 | mike | 5559999
```

- **Открыть базу** — выбираете `.txt`, приложение читает записи.
- **Создать** — заводите новый файл-базу.
- Каждое добавление/удаление **сразу сохраняется** в этот файл.

Файл портативен: скопируйте на флешку или в облако, откройте на другом
компьютере — все данные на месте.

## Excel — по желанию

Кнопка **«⬇ Excel»** выгружает цветную таблицу по месяцам (каждый месяц —
лист своего цвета). Это экспорт для печати/отправки; базой Excel **не
является**.

## Быстрый ввод

Заполните адрес, логин, номер (дата по умолчанию — сегодня) и нажмите
**Enter** — строка сохранится в базу, курсор вернётся в «Адрес».

## Запуск (Windows) — в отдельном окне

Дважды кликните **`Запустить.bat`** — приложение откроется в **отдельном
окне** (без вкладок и адресной строки, как обычная программа). Под капотом
поднимается локальный сервер на встроенном PowerShell и открывается окно
приложения в режиме `--app` (Edge или Chrome). Ничего устанавливать не
нужно.

Свёрнутое окно консоли — это сервер; его закрытие останавливает приложение.

> ⚠️ Не запускайте `app.js` / `sw.js` двойным кликом — Windows выполнит их
> как системный скрипт и выдаст ошибку. Запускается только приложение
> целиком — через `Запустить.bat`.

### Любая ОС (если установлен Node)
```bash
npx serve .
```

## Браузеры

- **Chrome / Edge** — полноценно: запись прямо в файл базы
  (File System Access API), путь к базе запоминается между запусками.
- **Firefox / Safari** — открытие файла через выбор, сохранение — кнопкой
  «Сохранить базу».

## Установка как приложение (PWA)

Помимо `--app`-окна можно установить приложение «по-настоящему»: кнопка
**«⤓ Установить»** в шапке (Chrome/Edge) или «На экран Домой» (iOS Safari).
Работает офлайн.

## Технологии

Чистый статичный сайт без сборки и без внешних CDN (всё работает офлайн):

- **Своя текстовая база** + **File System Access API** — чтение/запись
  файла базы напрямую.
- [ExcelJS](https://github.com/exceljs/exceljs) (локально, `js/vendor/`) —
  экспорт цветного `.xlsx`.
- **Service Worker + manifest** — установка и офлайн.
- **IndexedDB** — запоминание ссылки на файл базы.
- Современный CSS: glassmorphism, `backdrop-filter`, `color-mix`, анимации.
