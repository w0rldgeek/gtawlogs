# Актуализация номеров абонентов

Готовый сайт для учёта номеров абонентов. **База данных — это сам
`.xlsx` файл**: ни сервера, ни хостинга, ни облака. Приложение читает
данные прямо из файла и пишет изменения обратно в него же.

## Поля

- **Адрес**
- **Логин**
- **Дата**
- **Номер телефона**

Записи раскладываются по месяцам (каждый месяц — отдельный лист своего
цвета). Есть быстрый ввод, поиск/фильтр и удаление.

## Как это работает

Файл `.xlsx` выступает базой данных:

- **Открыть базу** — выбираете существующий файл, приложение читает из
  него все записи.
- **Создать** — создаёте новый файл-базу.
- Дальше каждое добавление/удаление **сразу сохраняется в этот файл**.

Файл портативен: скопируйте его на флешку или в облачную папку, откройте
на другом компьютере — увидите все данные. Можно открывать и обычным
Excel / Google Sheets.

## Быстрый ввод

Заполните адрес, логин, номер (дата по умолчанию — сегодня) и нажмите
**Enter** — строка сохранится в файл, курсор вернётся в «Адрес» для
следующей записи.

## Браузеры

- **Chrome / Edge** — полноценный режим: запись прямо в файл
  (File System Access API), привязка к файлу запоминается между сессиями.
- **Firefox / Safari** — File System Access не поддерживается: открытие
  файла через выбор, сохранение — кнопкой «Сохранить файл».

## Запуск

Откройте по `http(s)://` (нужно для доступа к файлу). Локально:

```bash
npx serve .
```

> Двойной клик по `index.html` (`file://`) не подойдёт — браузеры
> отключают File System Access на таких страницах.

## Технологии

Чистый статичный сайт без сборки: [ExcelJS](https://github.com/exceljs/exceljs)
(чтение/запись `.xlsx` с цветами) по CDN, File System Access API,
IndexedDB (запоминание ссылки на файл), современный CSS (glassmorphism,
`backdrop-filter`, `color-mix`).
