# Актуализация номеров абонентов

Готовый статичный сайт-таблица для учёта номеров абонентов. Никакого
бэкенда и сборки не требуется — открыл и работаешь.

## Поля

- **Адрес**
- **Логин**
- **Дата**
- **Номер телефона**

То, что вы заполняете в форме, **автоматически уходит в Excel-файл**
(.xlsx), разбитый по месяцам — каждый месяц своего цвета. Есть
поиск/фильтр и удаление; на странице показан предпросмотр того, что
записано в файл.

## Запуск

Просто откройте `index.html` в браузере. Либо поднимите локальный сервер:

```bash
npx serve .
```

## Запись в Excel

- **Chrome / Edge:** нажмите «📎 Привязать Excel», выберите или создайте
  `.xlsx` файл — и дальше каждая заполненная строка пишется прямо в него
  автоматически (File System Access API). Привязка запоминается.
- **Firefox / Safari:** автоматическая запись в файл недоступна — нажимайте
  «⬇ Скачать», чтобы получить актуальный `.xlsx`.

Файл формирует библиотека [ExcelJS](https://github.com/exceljs/exceljs)
(подключается по CDN), поэтому цвета вкладок и шапок сохраняются.

## Хранение данных

Данные дублируются в `localStorage` браузера — это источник для пересборки
файла и предпросмотра на странице. Excel-файл всегда отражает весь набор.

## Подключение бэкенда (потом)

Весь доступ к данным изолирован в объекте `Store` в `js/app.js`
(методы `all`, `add`, `remove`). Чтобы перевести сайт на общий бэкенд,
достаточно заменить тела этих методов на сетевые запросы к вашему API.

## Деплой

Любой статический хостинг: Vercel, GitHub Pages, Netlify. Файл
`vercel.json` уже включён для деплоя на Vercel.
